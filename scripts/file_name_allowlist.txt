# Paths built from a value called like a name (`name`, `table`, `schema`,
# `key`, `file`, `title`, `object`).
#
# Checked by `python3 scripts/lint.py file-names` over non-test code under
# `crates/`. A table, collection or object name comes from the server: it
# becomes a `dbflux_core::local_files::SafeFileName` and is placed with
# `confined_join`, never with a bare `join`. A site listed here must never
# see a server-provided name.
#
# Format: `path:function: reason`, one line per site. `function` is the
# innermost `fn` around it, so a function with two sites is listed twice.
# Reasons:
#   constant       - a fixed name, a uuid or a timestamp
#   local          - a name the user typed or picked on this machine
#   own path       - the last component of a path that already exists here
#   sanitized      - already a SafeFileName or sanitized by the caller
#   test support   - only used by tests

crates/dbflux/build.rs:main: constant (icon file of the release channel)
crates/dbflux_aws/src/config.rs:create_backup_for_path: constant (timestamped backup name)
crates/dbflux_core/src/config/scripts_directory.rs:create_file: local (script name typed by the user)
crates/dbflux_core/src/config/scripts_directory.rs:create_folder: local (folder name typed by the user)
crates/dbflux_core/src/config/scripts_directory.rs:rename: local (new name typed by the user)
crates/dbflux_core/src/config/scripts_directory.rs:move_entry: own path (name of the moved script)
crates/dbflux_core/src/config/scripts_directory.rs:import: own path (name of the imported local file)
