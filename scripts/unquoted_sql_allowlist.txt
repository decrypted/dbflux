# Format strings that put their own quotes around a placeholder.
#
# Checked by `python3 scripts/lint.py unquoted-sql` over the driver crates and
# dbflux_core. Names and values in generated SQL go through the dialect's
# quoting helper (`quote_identifier`, `qualified_table`, `value_to_literal`,
# or the driver's own helper). A site listed here must be provably safe.
#
# Format: `path:function: reason`, one line per format string. `function` is
# the innermost `fn` around it, so a function with two such strings is listed
# twice. Reasons:
#   quoting helper    - the helper itself; it escapes the quote it adds
#   escaped inline    - the value is escaped for exactly this quote on the line before
#   constant          - every value comes from a constant or a validated token
#   generated         - a timestamp, number or already-rendered literal list, never a name
#   not SQL           - display or error text that is never executed
